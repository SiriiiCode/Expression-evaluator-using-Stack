# Expression Evaluator using Stack (C)

This project performs infix to postfix conversion and evaluates postfix expressions using stack data structure in C.

## Features
- Infix to Postfix conversion
- Postfix expression evaluation
- Supports +, -, *, /, ^ operators
- Menu-driven program

## Data Structures Used
- Stack (Array implementation)

## How to Run
```bash
gcc Expressionevaluator.c -o expr
./expr
